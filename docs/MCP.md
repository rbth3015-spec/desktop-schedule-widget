# AI에게 말로 일정 넣기 (MCP)

> 한 번만 연결해 두면, Claude에게 **"내일 오후 3시 치과 일정비서에 넣어줘"** 라고 말하는 것으로 끝납니다.
> 달력에 바로 들어가고, 잘못 들어갔으면 위젯 아래에 뜨는 알림에서 **되돌리기** 한 번이면 됩니다.

## 한눈에 보기

```
 나  ──  "내일 3시 치과 일정비서에 넣어줘"  ──▶  Claude
                                                  │  연결 파일(mcp-schedule.js)을 부른다
                                                  ▼
                          받은함 폴더에 메모 한 장   (C:\Users\<나>\.schedule-widget\inbox)
                                                  │
                                                  ▼
                          일정관리 비서가 집어서 달력에 넣음  →  "밖에서 1건이 들어왔습니다"
```

- **MCP** 는 AI가 다른 프로그램을 '도구'로 쓰게 해 주는 연결 방식입니다.
  이 앱에는 연결 파일 `mcp-schedule.js` 가 하나 있고, 그걸 Claude에 등록해 두면 Claude가 필요할 때 알아서 부릅니다.
- 인터넷으로 나가는 것은 없습니다. 모든 일이 이 컴퓨터 안의 폴더 하나에서 일어납니다.

## 준비물 (처음 한 번)

1. **Node.js** — 연결 파일을 돌리는 프로그램입니다.
   PowerShell 에서 `node -v` 를 쳐서 `v20.10.0` 같은 숫자가 나오면 이미 있습니다.
   없으면 [nodejs.org](https://nodejs.org) 에서 **LTS** 를 설치하세요.
2. **연결 파일 `mcp-schedule.js`** — 이 저장소의 `tools/` 폴더에 있습니다.
   저장소를 받아 두지 않았다면 [이 파일 하나만](https://raw.githubusercontent.com/rbth3015-spec/desktop-schedule-widget/main/tools/mcp-schedule.js)
   내려받아 아무 폴더에 두면 됩니다(다른 파일은 필요 없습니다).

아래에서는 파일이 `C:\dev\schedule-widget\tools\mcp-schedule.js` 에 있다고 치겠습니다 — **내 위치로 바꿔 적으세요.**

## 연결하기 — Claude 데스크톱 (채팅 앱)

1. Claude 데스크톱에서 **설정 → 개발자 → 설정 편집(Edit Config)** 을 누릅니다.
   `claude_desktop_config.json` 파일이 열립니다.
2. 아래를 붙여 넣고 저장합니다.

   ```json
   {
     "mcpServers": {
       "schedule": {
         "command": "node",
         "args": ["C:\\dev\\schedule-widget\\tools\\mcp-schedule.js"]
       }
     }
   }
   ```

   - 경로의 `\` 는 **두 번**(`\\`) 적습니다. JSON 의 규칙입니다.
   - 파일에 이미 다른 내용이 있으면 `"mcpServers"` 안에 `"schedule": { … }` 덩어리만 더합니다
     (앞 항목과는 쉼표로 나눕니다).
3. Claude 데스크톱을 **완전히 껐다가 켭니다.** 창만 닫으면 안 되고,
   작업 표시줄 오른쪽(시계 옆)의 Claude 아이콘을 우클릭 → **종료**.
4. 새 대화에서 **"일정비서에 오늘 뭐 있어?"** 라고 물어봅니다.
   오늘 일정이 대답으로 오면 연결된 것입니다.

## 연결하기 — Claude Code (터미널)

```bash
claude mcp add --scope user schedule -- node "C:\dev\schedule-widget\tools\mcp-schedule.js"
```

- `--scope user` 를 붙여야 어느 폴더에서 열든 쓸 수 있습니다(빼면 지금 폴더에서만 됩니다).
- 확인: `claude mcp list` 에서 `schedule` 이 연결됨(✓)으로 보이면 됩니다.

## 이렇게 말하면 됩니다

| 이렇게 말하면 | 들어가는 것 |
|---|---|
| "내일 오후 3시 치과 일정비서에 넣어줘" | 내일 15:00 일정 |
| "다음 주 월요일부터 수요일까지 워크숍, 업무 태그로" | 사흘짜리 기간 일정 `#업무` |
| "금요일 보고서 마감, 중요 표시해서" | 금요일 일정 `!` |
| "내일 치과 3시, 모레 장보기, 금요일 회식 넣어줘" | 세 건을 한 번에 |
| "이번 주 목표에 '보고서 초안' 추가해줘" | 계획 › 이번 주 목표 |
| "일정비서에 오늘 뭐 있어?" | 오늘 일정 · 루틴을 읽어 줌 |
| "이번 주 일정 정리해줘" | 이번 주 일정을 날짜별로 읽어 줌 |

**'일정비서'** 라는 말을 넣으면 Claude가 이 도구를 쓸 차례라는 걸 확실히 압니다.

## 들어가면

- 위젯이 켜져 있으면 1초 안에 달력에 들어가고, 아래에 **`밖에서 1건이 들어왔습니다`** 가 뜹니다.
  잘못 들어갔으면 거기서 **되돌리기**.
- 위젯이 꺼져 있어도 괜찮습니다. 다음에 켤 때 들어갑니다.
  '내일' 은 **말한 날** 기준이라, 위젯을 하루 늦게 켜도 날짜가 밀리지 않습니다.

## 안심해도 되는 것

- AI는 일정을 **넣고 읽기만** 합니다. 지우거나 고칠 수는 없습니다.
- 포트를 열지 않고, 계정 · 비밀번호 · 토큰도 없습니다.
- 들어온 메모는 받은함의 `done` 폴더에 최근 50장까지 남아, 무엇이 들어왔는지 되짚을 수 있습니다.

## 안 될 때

| 증상 | 이렇게 |
|---|---|
| Claude가 도구를 안 쓰고 말로만 대답한다 | **'일정비서'** 를 넣어 말해 보기. 그래도 안 되면 Claude 데스크톱을 트레이에서 완전히 종료했다 켜기 |
| 설정 파일을 저장했더니 Claude가 오류를 낸다 | 쉼표 · 괄호가 맞는지, 경로의 `\` 를 `\\` 로 두 번 적었는지 |
| `node` 를 찾을 수 없다고 한다 | Node.js 설치 후 PC 재시작. 그래도 안 되면 `"command"` 에 `"C:\\Program Files\\nodejs\\node.exe"` |
| 넣었다는데 달력에 없다 | 날짜 확인(다른 달일 수 있습니다). 위젯 **설정 › 받은함 › 열기** 의 `done` 폴더에 메모가 있으면 들어온 것입니다 |
| 오늘 일정을 물었는데 예전 일정을 말한다 | 위젯을 Claude 앱 **안에서** 띄운 적이 있으면 생깁니다. 위젯은 시작 메뉴나 바탕화면에서 여세요 |
| 데이터 폴더를 옮겼다 | `"schedule"` 덩어리 안에 `"env": { "SCHEDULE_WIDGET_DIR": "D:\\내폴더" }` 를 더합니다 |

## 참고 — Claude가 쓰는 도구

| 도구 | 하는 일 |
|---|---|
| `add_task(text)` | 한 줄 문법으로 일정 추가(`치과 @내일 15:00 #건강 !`). 줄바꿈으로 여러 건 |
| `add_goal(title, scope)` | 이번 주 · 이번 달 목표 추가 |
| `list_today()` | 오늘 일정과 루틴 읽기 |
| `list_week(from?)` | 한 주 일정을 날짜별로 읽기 |

받은함이 AppData 가 아니라 사용자 폴더(`.schedule-widget`)에 있는 이유: Microsoft Store 에서 받은 Claude 데스크톱이
AppData 에 새로 만드는 파일은 Windows 가 Claude 전용 보관소로 옮겨 버려서, 위젯이 볼 수 없습니다.
